## Budget It

### Features:

Home Page:
* Users can connect to multiple bank institutions through the Plaid API.
* View all connected banks and see information such as available/current balances and credit card limits.
* View a summary of all the connected banks, such as total credit card debt, total savings, and total invested.

Transactions Page:
* Page for users to view their spending
* Can be viewed by individual bank account
* Breakdown by month, both written and chart view using the Recharts API

Budget Page:
* Users can create a budget for the month, broken down categorically
* Users can set monthly income and yearly savings goal
* Users will get feedback about whether the budget is realistic based on income and saving goals

Analysis Page:
* Users have 2 different breakdowns that they can view
* Monthly: Will compare how much was planned to spend vs how much was spent (by category)
* Yearly: can view spending trends from the years, so how much was spent per month
